# Siren Classifier FPGA Accelerator

Binary audio classifier deployed on a PYNQ-Z2 FPGA board.

| Property | Value |
|---|---|
| Model | 41 -> 4 -> 2 MLP |
| Task | Ambulance vs Firetruck siren classification |
| Parameters | 178 |
| FPGA | Zynq XC7Z020 (PYNQ-Z2) |
| Interface | AXI-DMA + AXI-Stream |
| Precision | Q4.12 fixed-point |
| Throughput | > 1 M inf/s (FPGA, 100 MHz) |
| Latency (ARM sim) | ~6 ms per inference |

## Feature Extraction Pipeline (41 features)

Input: WAV file (any sample rate)

1. Read WAV, convert to float32 in [-1, 1]
2. Stereo -> mono (average channels)
3. Peak-normalise
4. Resample to 16000 Hz
5. Spectrogram: `hann(512)`, `noverlap=256`, `scaling='spectrum'`, `mode='magnitude'`
6. `log1p` compression
7. **32 spectral features**: 8 frequency bands x 4 stats (mean, std, p25, p75)
8. **5 waveform stats**: mean, std, abs-mean, abs-max, abs-p90
9. **4 band-energy means**: [0,300), [300,1000), [1000,3000), [3000,8000) Hz
10. Standardise: `(x - feature_mean) / feature_std`

## Model Architecture

```
Input (41)
  |
Linear(41 -> 4) + ReLU
  |
Linear(4 -> 2)
  |
argmax -> class index (0=ambulance, 1=firetruck)
```

Training config: `lr=0.01`, `wd=1e-4`, `batch=32`, `max_epochs=80`, `patience=12`

## FPGA Implementation

### HLS Kernel (`mlp_top.cpp`)
- `ap_ctrl_none` — free-running AXI-Stream (no AXI-Lite control port)
- Q4.12 fixed-point (`ap_fixed<16,4>`)
- Weights stored in on-chip LUTRAM (only 178 int16 values)
- In: 41 uint32 words (Q4.12 features, bits[15:0])
- Out: 1 uint32 (argmax: 0 or 1, TLAST=1)

### Block Design
```
PS7 -> AXI-IC-Ctrl -> AXI-DMA
AXI-DMA.MM2S  -> HLS-IP.s_axis_input
HLS-IP.m_axis_output -> AXI-DMA.S2MM
AXI-DMA -> AXI-IC-HP0 -> PS7.S_AXI_HP0
```

### DMA Transfer Sizes
| Channel | Words | Bytes |
|---|---|---|
| MM2S (host -> FPGA) | 41 x uint32 | 164 B |
| S2MM (FPGA -> host) | 1 x uint32  | 4 B   |

## Manual Step-by-Step Build

```powershell
# Step 0: Generate weights header
cd MLP\fpga\hls
python generate_weights.py  --ckpt "C:\...\best_model.pt"

# Step 1: Vitis HLS
cd MLP\fpga\hls
run_hls_here.bat            # calls: vitis_hls -f run_hls.tcl

# Step 2: Unzip IP
cd MLP\fpga
Expand-Archive hls_ip.zip -DestinationPath hls_ip

# Step 3: Vivado
cd MLP\fpga\vivado
run_vivado_here.bat         # calls: vivado -mode batch -source create_project.tcl

# Step 4: Extract .hwh
cd MLP\fpga
python pynq\extract_hwh.py

# Step 5: Copy feature stats (run once to cache)
python -c "
import torch, numpy as np
ck = torch.load(r'C:\...\best_model.pt', weights_only=False, map_location='cpu')
np.savez('MLP/fpga/pynq/feature_stats.npz', mean=ck['feature_mean'], std=ck['feature_std'])
"

# Step 6: Deploy to board
cd MLP\fpga
python pynq\deploy.py
```

## On-Board Inference (JupyterLab)

1. Connect PYNQ-Z2 via USB-Ethernet (`192.168.2.99`)
2. Open `http://192.168.2.99:9090` (password: `xilinx`)
3. Navigate to `siren_mlp/`
4. Open `mlp_inference_pynq.ipynb`
5. Run all cells (`Kernel -> Restart & Run All`)
6. Upload a `.wav` file and click **Run FPGA Inference**

**Troubleshooting**: If `RuntimeError: Could not open device with index '0'`:
- Always run `.ipynb` files from JupyterLab (as root), NOT `python script.py` from terminal
